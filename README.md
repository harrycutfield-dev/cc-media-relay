# cc-media-relay

Scratch image relay for ActivePipe uploads. **This is not a website.**

ActivePipe can fetch from `raw.githubusercontent.com` (CORS `*`) and POST the bytes to its
own /images endpoint. Staging images here instead of in the website repo means no Netlify
production build is triggered and no scratch file publishes to harrisoncutfield.co.nz.

Do NOT connect this repo to Netlify.

Contents are throwaway: listing photos already public on Trade Me, and generated email
banners. Nothing client-identifying or unpublished belongs here.
